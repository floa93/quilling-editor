# Quilling Editor

A browser-based editor for designing paper quilling artwork. Draw paper strips freehand or drag
classic quilling shapes (coils, teardrops, scrolls, …) onto the canvas, then export the design
as SVG and import it again later.

**Live app:** https://floa93.github.io/quilling-editor/

It is a purely static site: plain HTML, CSS and JavaScript (ES modules), with no backend, no
database and no runtime dependencies. Your current design is auto-saved in the browser's
`localStorage`.

## Features

- **Draw**: smoothed vector strokes with an optional paper-strip look, color palette plus custom color, strip width 1–20 px
- **Shapes**: 12 quilling templates (tight/loose coil, teardrop, marquise, square, triangle, half moon, heart, leaf, S/C/V-scroll) by drag and drop or tap
- **Edit**: select, shift-click/rubber-band multi-select, move, scale (Shift keeps the aspect ratio), rotate (Shift snaps to 15°), recolor, duplicate, copy/paste, z-order, delete, eraser
- **Undo/redo** with 100 steps
- **SVG export/import**: lossless round trip for the editor's own files; generic SVGs are imported as editable paths and sanitized first
- **Mobile**: bottom toolbar, bottom sheets, pinch zoom and two-finger pan, two-finger scale/rotate of the selection, pen palm rejection, installable as a home-screen app

| Action | Shortcut |

| Select / Draw / Eraser | `V` / `B` / `E` |
| Undo / Redo | `Ctrl/Cmd+Z` / `Ctrl/Cmd+Shift+Z` or `Ctrl+Y` |
| Delete | `Delete` / `Backspace` |
| Duplicate / Copy / Paste | `Ctrl/Cmd+D` / `Ctrl/Cmd+C` / `Ctrl/Cmd+V` |

| Pan | Space + drag or middle mouse button |

## Run locally

Requires [Node.js](https://nodejs.org/) 20 or newer. No `npm install` is needed: there are no dependencies.

```sh
npm start          # serves the app at http://localhost:8080/ (PORT=xxxx to change)
npm test           # runs the unit tests (node:test)
npm run build      # copies the static site into _site/
```

Because the app uses ES modules, open it through a web server (as `npm start` does), not via `file://`.

## Project structure

```
index.html, styles.css, manifest.webmanifest, icons/   static site
src/app.js         editor controller: tools, gestures, panels, import/export UI
src/renderer.js    renders the document and the selection overlay into the SVG canvas
src/model.js       document/element model (immutable updates, transforms, z-order)
src/templates.js   generators for the quilling shape templates
src/svg.js         SVG export, import (native + generic) and sanitizing
src/xml.js         small strict XML parser used by the importer
src/geometry.js    matrices, path parsing/flattening, smoothing, hit testing
src/history.js     undo/redo
src/storage.js     localStorage auto-save
tests/             unit tests for the core logic
scripts/           build, local server, icon generator
```

### SVG format

Exports are SVG 1.1. Each element is a `<g>` with a `transform` and one or more `<path>`
layers (the base strip plus, with the paper look, a face and a highlight). Editor data
(element type such as `stroke` or `template:teardrop`, color, width and transform values) is
stored in attributes of the private namespace `urn:quilling-editor:1` (prefix `quill`).
Viewers ignore these attributes, and the editor uses them to restore every element exactly.

### Icons

`icons/icon.svg` is generated by `node scripts/make-icons.mjs`. The PNG icons were rendered
from those SVGs once and are committed.

## Deployment

`.github/workflows/deploy.yml` runs on every push to `main`:

1. **build** job: install Node, run `npm test`, run `npm run build`, upload `_site/` as the Pages artifact
2. **deploy** job: runs only when the build job succeeded, and publishes the artifact to GitHub Pages

If the tests or the build fail, nothing is deployed and the previous version stays online.
Pull requests run the tests without deploying. All asset paths are relative, so the app works
under the `/quilling-editor/` sub-path; the build fails if `index.html` contains absolute asset paths.

The repository's Pages source must be set to **GitHub Actions** (Settings → Pages).
